# Image Quantization 🖼️  

## 📌Overview   
This project implements an **image quantization algorithm** in **C#** using **clustering techniques** and the **Minimum Spanning Tree (MST)** approach.  
The algorithm reduces the number of distinct colors in an image while preserving visual quality by:  
- Constructing **color graphs**  
- Generating **optimized color palettes**  
- Applying quantization to images  

## Features   
- Image input and processing   
- Color graph construction using MST   
- Automatic color palette generation   
- Color quantization to reduce image size   
- Efficient clustering for better performance   

## Tech Stack   
- **Language:** C#  
- **Algorithms:** Clustering, Minimum Spanning Tree (MST)  
- **Data Structures:** Graphs, Trees  

## Applications 

* Image compression
* Digital art & design
* Computer vision preprocessing
* Reducing image storage requirements
